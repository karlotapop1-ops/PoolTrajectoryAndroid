# Pool Trajectory — Android prototype 0.1

Проект-заготовка Android-приложения для Samsung Galaxy A34 / Android 16.

## Что уже реализовано
- Экран приложения с запуском теста.
- Запрос разрешения Android MediaProjection на захват экрана.
- Foreground service с типом `mediaProjection`.
- Получение кадров через `ImageReader`.
- Прозрачное некликабельное окно поверх приложений.

## Что пока НЕ реализовано
- Автоматическое распознавание шаров и границ стола.
- Расчёт траекторий битка и прицельного шара.
- Многоцветные линии в реальном времени.
- Готовый APK.

Это честный технический каркас первого этапа, а не готовый мод и не готовый APK. Захват экрана требует явного системного согласия пользователя и постоянного уведомления. Android может показывать индикатор захвата.

## Сборка
Открой папку проекта в Android Studio (версия с поддержкой Android Gradle Plugin 8.9.1 и SDK 36), дождись Gradle Sync и собери `app`.

Если собираешь только с телефона, потребуется Android IDE, поддерживающая Kotlin + Gradle + Android SDK 36. Не устанавливай APK из неизвестных источников.

## Следующий этап
Добавить обработку кадров: обнаружение игрового стола, шести луз, битка и цветных шаров. Затем реализовать геометрическую модель столкновений и рисование траекторий поверх игры.

## Примечание о правилах игры
Использование сторонних подсказок/оверлеев в онлайн-играх может противоречить правилам игры и привести к ограничениям аккаунта. Используй прототип только там, где это разрешено.

## Сборка без ПК через GitHub Actions (с телефона)
1. Создай новый пустой репозиторий на GitHub.
2. Распакуй ZIP и загрузи ВСЕ файлы и папки проекта в корень репозитория, включая скрытую папку `.github`.
3. Открой вкладку Actions и разреши запуск workflows, если GitHub попросит.
4. Запусти workflow `Build Android APK` кнопкой `Run workflow` (или дождись сборки после push).
5. Открой завершившийся запуск и скачай artifact `PoolTrajectory-debug-apk`.
6. Распакуй artifact и установи `app-debug.apk`. Android может попросить разрешить установку из этого источника.

Если загрузка через мобильный браузер не показывает скрытую папку `.github`, добавь workflow-файл отдельно через сайт GitHub: `.github/workflows/build-apk.yml`.

Внимание: сборка может завершиться ошибкой, если конфигурация SDK/Gradle изменится; присылай лог ошибки, чтобы исправить.
